# Changelog

All notable changes to bateri are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

Write user-facing changes under **Unreleased** as they land. At release time
rename it to the new version and date; `make yayin` sends that section to the
site as the release notes shown in the update window.

## [0.1.0] - 2026-09-28

First public release.

### Added

- GPU-rendered terminal for macOS (Metal), with command blocks, the input dock, tabs and splits.
- Search in scrollback, mouse selection, and drag-and-drop uploads over SSH.
- Automatic updates.
